# 🎓 EGC C++ Capstone Projects

## 📌 About the Repository
This repository contains two C++ console-based capstone projects developed as part of the EGC academic program. The projects apply programming concepts to practical scenarios, focusing on data management, problem-solving, algorithms, and file handling.

They cover two different domains: university academic management and hospital patient management.

---

## 📚 Project 1: University Course Registration & Academic Advising System

### Overview
A console-based application for managing university courses and student academic records. It supports student registration, course enrollment, prerequisite verification, credit-hour limits, and GPA calculations.

### Key Features
* **Course Management:** Add and display available courses.
* **Student Registration:** Create student profiles with unique IDs, major codes, and credit limits.
* **Course Enrollment:** Check prerequisites, course capacity, and credit limits before registration.
* **Schedule Management:** Drop courses and view registered schedules.
* **GPA Calculation:** Calculate GPA based on completed courses and recorded grades.
* **Academic Transcripts:** Generate unofficial transcript files for individual students.
* **File Handling:** Store and retrieve student and course information using text files.

---

## 🏥 Project 2: Hospital Patient Triage & Ward Management System

### Overview
A console-based application for managing patient registration, triage priorities, ward allocation, and hospital bed availability. It also records important patient-related operations for tracking purposes.

### Key Features
* **Patient Registration:** Record patient details, including name, age, ID, symptom code, and triage priority.
* **Priority-Based Triage:** Organize patients by urgency, prioritizing critical cases.
* **Ward Management:** Track bed availability across ICU, General, and Emergency wards.
* **Patient Assignment & Discharge:** Assign patients to available beds and update occupancy records upon discharge.
* **Occupancy Reports:** Display occupied and available beds in each ward.
* **Audit Logging:** Record patient admissions, status changes, and discharges with timestamps.
* **Role-Based Menus:** Provide separate interfaces for Receptionists and Doctors.
